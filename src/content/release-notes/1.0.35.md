## Une reformulation plus fiable, sans friction

Nova utilise désormais d'abord l'Intelligence privée locale, puis bascule automatiquement vers Turbo si le moteur local ne peut pas produire un résultat fiable et si votre abonnement le permet. Le mode local strict reste disponible pour ne jamais envoyer le texte en ligne.

La reformulation comprend mieux les corrections prononcées en cours de dictée, conserve les dates, les nombres et l'intention, et ne répond plus aux questions présentes dans le texte. Les termes techniques courants comme « GitHub », « API », « GPU » ou « IBAN » sont aussi normalisés plus précisément.

Le menu Debug affiche maintenant les journaux récents dès son ouverture, avec des diagnostics structurés qui permettent d'identifier rapidement le moteur utilisé, les replis et les erreurs, sans enregistrer le contenu dicté.
