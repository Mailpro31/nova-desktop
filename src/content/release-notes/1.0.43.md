## Essayer la connexion par adresse e-mail avant la publication DNS

Pour les services informatiques qui veulent essayer la connexion par adresse e-mail avant d'avoir publié l'enregistrement DNS de leur organisation : la variable d'environnement `NOVA_EMAIL_DISCOVERY_OVERRIDE`, posée sur un poste, indique à Nova quel serveur utiliser pour un domaine (`ecole.fr=https://serveur-de-test`).

Elle ne vaut que sur la machine où elle est posée, et rien sur le réseau ne peut l'activer. Le serveur désigné doit toujours confirmer qu'il sert le domaine. Sans cette variable, rien ne change : Nova lit le DNS comme dans la version précédente.
