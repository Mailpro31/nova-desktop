## Un snippet vocal peut coller une image

Dans Snippets vocaux, le bouton « Ajouter une image » associe une image à votre snippet : un schéma, un logo, une signature. Vous pouvez aussi déposer l'image sur la zone de texte. Quand vous dites le snippet, Nova colle l'image dans Word, OneNote ou Google Docs ; une application qui n'accepte que du texte, comme le Bloc-notes, reçoit seulement le texte du snippet.

L'image reste sur cet ordinateur. Sur un autre poste, le snippet colle son texte, sans l'image.
